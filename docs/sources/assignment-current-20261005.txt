001: Individual Assignment: Financial Decentralized Application (DApp)
002: I. BackgroundDecentralized Applications (DApps) are transforming the financial industry by enabling secure, transparent, and trustless digital transactions without relying on centralized intermediaries. In this assignment, you will design and develop a financial DApp that demonstrates your understanding of blockchain technology, smart contracts, and full-stack web development.Your solution should solve a real-world financial problem by integrating blockchain technology with a user-friendly web application.
003: II. Learning Objectives
004: Explain the fundamentals of blockchain and decentralized applications.
005: Design and implement Ethereum smart contracts using Solidity.
006: Develop a full-stack DApp integrating blockchain with a web interface.
007: Evaluate the security, usability, and performance of a DApp.
008: Demonstrate practical applications of decentralized finance (DeFi).
009: III. Project Requirements
010: Develop an original Financial DApp.
011: Include a Solidity smart contract.
012: Support MetaMask wallet connection.
013: Provide a user-friendly web interface.
014: Integrate a backend using Flask or Node.js.
015: Execute blockchain transactions.
016: Display transaction status/history.
017: Implement input validation and error handling.
