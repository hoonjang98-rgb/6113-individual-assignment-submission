FREELANCEPAY / LOCAL SETUP

Deploy your invoice contract.

This page deploys the tested FreelancePay contract to Ethereum Sepolia. It uses MetaMask in this browser and test ETH for the network fee. No real ETH payment is requested.

Before you begin

Use a test account in MetaMask with Sepolia ETH. You will also need a second test account for the client payment later. This page never asks for a password, private key or recovery phrase.

If you need test ETH, use a faucet listed on the Ethereum Sepolia network page. Faucet availability and requirements vary.
